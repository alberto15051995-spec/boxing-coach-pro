BOXING COACH PRO · PWA V18

PUBLICACIÓN HTTPS
1. Sube TODOS los archivos de esta carpeta a un hosting estático HTTPS.
2. index.html debe quedar en la raíz junto a manifest.webmanifest, sw.js e iconos.
3. Abre la URL HTTPS en Chrome Android.
4. Pulsa CÁMARA ESPEJO y concede Cámara.
5. Chrome podrá ofrecer Instalar app / Añadir a pantalla de inicio.

IMPORTANTE: abrir index.html desde Descargas (content:// o file://) seguirá sin ser el modo correcto para la cámara/PWA.
