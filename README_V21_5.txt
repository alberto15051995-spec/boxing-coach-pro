BOXING COACH PRO V21.5 — CIERRE TEMPORAL DE ACCIÓN

Cambios principales:
- Reconocimiento de tren superior ya no requiere piernas/tobillos.
- Una acción se analiza como secuencia temporal, no como una pose aislada.
- Golpe: SALIDA -> EXTENSIÓN/PICO -> RETORNO -> ACCIÓN COMPLETA.
- Guarda el pico máximo de desplazamiento aunque ocurra entre fotogramas.
- Zona de retorno a guardia deliberadamente amplia.
- Timeout evita bloqueos permanentes.
- Slip: desplazamiento de cabeza -> pico -> retorno al centro.
- El motor visual V21.5 tiene propiedad exclusiva del HUD.
- Diagnóstico muestra velocidad/desplazamiento L y R y desplazamiento H.

Prueba recomendada:
5 jabs, 5 directos, 5 slips izquierda y 5 slips derecha.
No añadas ganchos/uppercuts todavía: primero validar este núcleo.
